### Git 历史重写（已执行，用户确认）
- 目的：明文口令残留在 5 个已推送的历史提交里（早期 `.workbuddy/memory` 日志 + 旧 `main.py`），仓库是**公开**的。
- 工具：`git-filter-repo`（装到 `~/.workbuddy/binaries/python/envs/default`），替换规则文件每行 `旧串==>新串`。
- **必须先备份 `.git`**（重写不可逆）：`cp -r .git /tmp/git-backup-<时间戳>`。
- 命令：`python -m git_filter_repo --replace-text /tmp/replacements.txt --force`，21 个提交重写耗时 3.3s。
- 坑：① filter-repo 会**移除 origin remote**，事后要 `git remote add` 回来；
  ② 本地残留的 `agent-dev` 等旧分支也会被一起重写（可删）；
  ③ 重写后必须 `git push -f origin master:main`。
- 服务器那份 clone 历史已失效，**不能用 `git pull`**，要 `git fetch origin main && git reset --hard origin/main`
  （**务必先备份 `app/campus_bot.db`**，它在 git 之外，reset --hard 不动它但 glove 保险起见仍要备份）。
